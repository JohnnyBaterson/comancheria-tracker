# Comanchería

A single-screen digital tabletop companion for *Comanchería: The Rise and Fall of the Comanche Empire*.

Open the GitHub Pages site in a modern browser. Select your local Tabletop Simulator `Mods/Images` folder to display your own board and component artwork. Your artwork and game data remain in your browser.

Unofficial fan-made companion, not affiliated with or endorsed by GMT Games. Board and game artwork belong to their respective rights holders.
