# Comanchería Digital Tabletop

Upload these files to the repository root for GitHub Pages, keeping the `assets/` directory.

No original game artwork is included. In the game, choose **Import TTS assets**, then select your existing Tabletop Simulator `Mods/Images` folder. The original filename-based importer associates board, card sheets, History cards and counter faces locally and caches them in this browser. No images are uploaded to GitHub.

If no artwork appears, check the importer’s scan results for missing source filenames. The browser must retain site storage for art to persist. Saved-game import remains disabled.
