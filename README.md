# Comanchería Digital Tabletop

Private, browser-based companion for *Comanchería: The Rise and Fall of the Comanche Empire*.

## Run

Open the site through GitHub Pages (or any static web server). No installation, build step, or backend is needed. Game saves stay in the browser used to play.

## GitHub Pages

Upload the contents of this folder to the **root of a private repository**. In **Settings → Pages**, deploy from your chosen branch (`/root`). Open the Pages URL after publishing.

**Artwork notice:** `assets/original-art/` contains game artwork and is included only for your personal private use. Do not publish this package in a public repository unless you have the rights to distribute these images. GitHub Pages visibility can differ from repository visibility; check the Pages site's access before enabling it.

Independent fan project; not affiliated with or endorsed by GMT Games. Some card procedures still require manual resolution. Save imports are disabled.
